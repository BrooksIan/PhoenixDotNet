Bay checklist

  • Seed parts inventory: ./use-cases/vehicle360/create_vehicle360_tables.sh
  • Mount Phoenix views with the yellow buttons, then hit Execute Command
  • Run VIN / JOIN lookups with Execute Query
  • Confirm racks with List Views: ENGINE*, DEVICE*, *_BUILD, VEHICLE

Parts layout

  • ENGINE, TRANSMISSION, CHASSIS — type catalogs
  • DEVICE — shared manufacturing equipment
  • DEVICE_SESSION — production-run log per device session
  • ENGINE_BUILD, TRANSMISSION_BUILD, CHASSIS_BUILD — physical units + production + device + session
  • VEHICLE — VIN key; links one of each build ID
  • Complete build sheet = VIN → builds → types / devices / sessions
